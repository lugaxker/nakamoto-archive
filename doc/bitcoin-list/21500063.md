# [bitcoin-list] Bitcoin v0.1.5 released

From: Satoshi Nakamoto <satoshi@vistomail.com\> - 2009-02-04 19:46:04

Version 0.1.5 is now available. &nbsp;It includes the fix for the problem Nicholas had, checking for disk full and changes to try to improve things that were confusing.

Special thanks to Nicholas and Dustin for all their help and feedback!

Download link:<br>
http://sourceforge.net/project/showfiles.php?group_id=244765&package_id=298441

Changes:<br>
\- disk full warning<br>
\- fixed a bug that could occur if dns lookup failed<br>
\- prevent entering your own address in the address book, which confusingly changed the label for your own address<br>
\- moved change address button to menu under options<br>
\- tweaks to make it get connected faster<br>
\- close sockets on exit<br>
\- created minimum fee for transactions less than 1 cent<br>
\- hid the transaction-type selection box that only had one choice<br>
\- cleaned up ParseMoney a little<br>
\- slightly cleaner reformatting of message text<br>
\- changed the font in transaction details dialog<br>
\- added some explanation text to transaction details for generated coins<br>
\- reworded the description for transactions received with bitcoin address
